개인정보처리방침

시행일: 2026년 11월 9일 · 부동산 정보 룽숏

"부동산 정보 룽숏"(이하 "이 앱")은 운영자 본인의 YouTube 채널에 부동산 뉴스 요약 영상을 업로드하기 위해 YouTube API 서비스를 사용하는 개인용 도구입니다. 이 앱은 다른 사용자에게 서비스를 제공하지 않습니다.

1. YouTube API 서비스 사용

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 사용하면 YouTube 서비스 약관에 동의하는 것으로 간주되며, Google의 개인정보 처리는 Google 개인정보처리방침을 따릅니다.

2. 접근하는 정보

Google 계정 승인을 통해 다음 권한만 요청합니다.

  • YouTube 동영상 업로드 (youtube.upload): 운영자가 만든 영상과 제목·설명·태그·썸네일을 운영자의 채널에 올리기 위해 사용합니다.
  • YouTube 계정 읽기 (youtube.readonly): 업로드할 채널 이름을 확인하기 위해서만 사용합니다.

이 앱은 이메일, 연락처, 시청 기록, 댓글 등 다른 개인정보를 수집하지 않습니다.

3. 정보의 사용과 저장

  • Google이 발급한 승인 토큰은 운영자의 컴퓨터에만 파일로 저장되며, 외부 서버로 전송되지 않습니다.
  • 업로드한 영상의 ID와 제목은 운영자 컴퓨터의 기록 파일에만 남습니다.
  • 이 앱은 별도의 서버나 데이터베이스를 운영하지 않습니다.

4. 제3자 제공

이 앱은 어떤 정보도 판매하거나 제3자에게 제공하지 않습니다. 업로드 요청은 Google(YouTube)에만 전달됩니다.

5. 권한 철회와 삭제

언제든지 Google 계정 보안 설정에서 이 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 승인 토큰은 더 이상 사용할 수 없으며, 운영자는 컴퓨터에 저장된 토큰 파일을 삭제합니다.

Privacy Policy (English)

Effective: November 9, 2026

"부동산 정보 룽숏" (the "App") is a personal tool that uses YouTube API Services to upload short real-estate news summary videos to the operator's own YouTube channel. It does not provide services to other users.

YouTube API Services. The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Data accessed. Only the scopes youtube.upload (to upload videos, titles, descriptions, tags and thumbnails) and youtube.readonly (to read the channel name). No other personal data is collected.

Use and storage. OAuth tokens are stored only as a local file on the operator's computer and are never sent to any other server. Uploaded video IDs and titles are kept only in a local log file. The App runs no servers or databases.

Sharing. No data is sold or shared with third parties. Requests are sent only to Google (YouTube).

Revoking access. Access can be revoked at any time via Google security settings, after which the local token file is deleted.
